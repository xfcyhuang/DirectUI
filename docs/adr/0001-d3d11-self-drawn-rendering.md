# 渲染采用纯 D3D11 自绘,不走 D2D 互操作

本项目定位即「D3D11 实现的 UI 库」,因此绘制栈决定为纯 D3D11 自绘:图元用自写 HLSL 着色器(SDF 圆角矩形、渐变、九宫格贴图)绘制;文字用 DirectWrite 做排版与字形分析(`IDWriteGlyphRunAnalysis` 栅格化为 alpha 纹理),全程不经 Direct2D。拒绝了 D2D-on-D3D11 互操作方案——那等于用 D2D 写 UI,引入双层 API 与互操作同步负担,且违背项目目标。

## Considered Options

- **纯 D3D11 自绘(选定)**:可控性与学习价值最高;代价是必须自建字形图集(glyph atlas),是文字阶段最大的工作量来源。
- **D2D1 互操作**:矢量与文字最快落地,但绘制栈被 D2D 主导,后期反悔成本极高。

## Consequences

- 整条绘制栈(着色器、顶点格式、纹理图集)与其他路线不兼容,此决策实际不可逆。
- 文字质量上限取决于自建字形图集的滤波与子像素定位,验收时需与原生渲染对拍。
