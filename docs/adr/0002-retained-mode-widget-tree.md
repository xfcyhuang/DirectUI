# 控件模型采用 retained-mode 树,拒绝 immediate-mode

控件是持久化的树形结构(聚合 struct + `std::variant` 表达种类,无继承体系),脏区驱动重绘,事件沿树路由。项目目标是「逐步实现各种控件」的库,immediate-mode(imgui 风格每帧重新声明 UI)下「控件库」这一概念本身不成立;持久树也是脏区优化与事件路由的前提。此选择与代码规范(自由函数 + 聚合 struct,禁止继承)互为印证。

## Consequences

- 窗口阶段就必须预留:树节点身份标识、脏区标记接口、事件路由入口——即使 v0 尚无任何控件。
- 控件种类以 variant 表达,新增控件 = 新增 variant 备选 + 对应自由函数处理集,而非新类。
